# SHAKTI | Personal Safety Application

A technology-driven personal safety application designed to make emergency assistance more accessible through intuitive interfaces and location-aware features.

## About the Project

Shakti is a personal safety application developed to explore how technology can support individuals in emergency situations through accessible safety tools and community-oriented assistance.

## Features

- **SOS Interface:** An accessible emergency activation interface.
- **Live Map:** Location visualisation through an interactive map.
- **Community Support:** A dedicated community interface.
- **Help & Assistance:** An interface for accessing safety-related assistance.
- **Settings:** Application configuration options.

*Note: Feature availability and operational capabilities depend on the current implementation.*

## Technology Stack

- React.js
- JavaScript
- HTML5

- Vite

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   `git clone https://github.com/Manasastack/shakti-women-safety-app.git`

2. Navigate into the project:

   `cd shakti-women-safety-app`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in your terminal.
